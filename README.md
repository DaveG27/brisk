# Brisk Mail

A fast, colour-coded Gmail app for Android.

Each push to `main` builds a signed APK with GitHub Actions and publishes it to the **latest** release. Download `Brisk.apk` from Releases on your phone and open it to install or update.

Add as many accounts as you like: Gmail, Virgin Media (virginmedia.com, virgin.net, ntlworld.com, blueyonder.co.uk), Yahoo, iCloud or any IMAP email, each with an app password. "All inboxes" shows them together.
